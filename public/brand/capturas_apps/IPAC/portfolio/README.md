# Capturas para portfolio

Capturas tomadas desde la aplicación local de IPAC con datos de demostración, en tema oscuro.

## Desktop

- `01-dashboard-desktop.png` — resumen operativo, sucursales, caja y cobranzas.
- `02-alumnos-directorio-desktop.png` — directorio académico con filtros y ficha lateral.
- `03-alumno-cuenta-desktop.png` — ficha del alumno y resumen de cuenta corriente.
- `04-deudores-cobranzas-desktop.png` — cartera de deudores con filtros de gestión.
- `05-caja-diaria-desktop.png` — caja diaria, conciliación y acciones de tesorería.
- `06-reportes-resumen-desktop.png` — filtros, categorías y métricas financieras.
- `07-importar-datos-desktop.png` — carga controlada desde Excel/CSV y plantillas.

## Mobile

Todas las capturas mobile usan viewport `390x844`.

- `08-alumnos-directorio-mobile-390x844.png` — filtros apilados y tarjetas responsive.
- `09-dashboard-mobile-390x844.png` — indicadores operativos y selector de sucursal.
- `10-caja-diaria-mobile-390x844.png` — acciones de caja adaptadas a toque.
- `11-reportes-mobile-390x844.png` — filtros y navegación por categorías en mobile.

Las capturas se encuadraron para portfolio y no incluyen la fila de datos personales del padrón.
